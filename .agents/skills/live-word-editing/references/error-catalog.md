# Live Word Error Catalog

Reference catalog mapping Live Word COM error states to user explanations and forbidden actions.

| Situation | Exact Message Pattern | What to Tell the User | What NOT to Do |
|---|---|---|---|
| **Target index out of range** | `Index [p:{target_index}] is out of range ({valid_range}).` | Inform the user that the paragraph index does not exist in the document's body, and provide the valid range from the latest outline. | Do NOT guess or hallucinate indices. Do NOT retry blindly. |
| **Read-only or protected** | `The document '{file_name}' is read-only or protected ({state}). Please enable editing in Microsoft Word.` | Ask the user to switch to Microsoft Word and disable document protection or enable editing permissions. | Do NOT attempt to force write or modify the document file via low-level scripts. |
| **Protected View** | `The document '{file_name}' is open in Protected View. Please click 'Enable Editing' in Microsoft Word.` | Advise the user to click the yellow "Enable Editing" banner in their Microsoft Word application window. | Do NOT close or reopen the document. |
| **Cloud-hosted (OneDrive/SharePoint)** | `The document '{file_name}' is cloud-hosted on OneDrive/SharePoint ({url}). Please save or copy it locally, or close it in Word and set WORD_BACKEND=headless.` | Explain that cloud-synced documents cannot be reliably addressed via local COM paths without local caching; offer to work with a local copy or close Word. | Do NOT attempt to mutate HTTP URLs directly. |
| **Modal dialog or call timeout** | `Word may be waiting on a modal dialog or is not responding (call timed out after {timeout}s). Please check Microsoft Word and dismiss any open dialogs.` | Tell the user that Word has an open dialog (e.g., Save As, Print, Font, or Alert) that is blocking COM IPC round-trips, and ask them to dismiss it. | Do NOT retry immediately or send new commands while poisoned. |
| **Worker poisoned** | `An earlier Word operation has not returned; Word is probably still blocked by a modal dialog. Please check Microsoft Word and dismiss any open dialogs.` | Explain that the background COM worker is paused until the modal prompt in Word is closed. | Do NOT spawn secondary background processes. |
| **Forced live not open** | `WORD_BACKEND is set to 'live', but the document '{file_name}' is not currently open in Microsoft Word.` | Tell the user that live mode was explicitly forced but the document is not active in Word; ask to open it in Word or unset `WORD_BACKEND`. | Do NOT launch Word automatically; the live engine only attaches to an already running instance. |
| **Lock file present but unattachable** | `The document '{file_name}' appears to be open in Word (lock file found), but could not be attached via COM. Word may be running elevated (as Administrator), in a different session, or the lock file is stale. Please close Word or verify the lock.` | Inform the user of permission boundaries (e.g., Word running as Admin while IDE is user-level) or stale `~$` lock files. | Do NOT delete `~$` lock files while Word is active. |
| **Tool not live capable** | `Tool '{tool_name}' is not yet live-capable in this phase. The file is open in Microsoft Word, so no changes were written to disk.` | Inform the user of tool status (all 8 tools are now fully live-capable). | Do NOT fall back to disk writes without user confirmation. |
