# Collaborative Problem Resolution

When encountering any error, unexpected failure, broken command, or bug:
1. **Stop immediately**: Do not attempt speculative fixes, alternative workarounds, or repeated retries without prior confirmation.
2. **Report clearly**: Provide a concise summary containing:
   - What failed (the exact command, action, or error message).
   - Relevant context or root cause hypothesis.
   - Potential paths forward or questions.
3. **Wait for guidance**: Let the user decide the next step so we can solve it together.
